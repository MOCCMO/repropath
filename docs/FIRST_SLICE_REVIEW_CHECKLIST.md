# First Slice Review Checklist

## Scope

- [ ] Only the curated project is available.
- [ ] Only `run-minimal-target` is implemented.
- [ ] No custom intake, reset control, storage migration, or seven-checkpoint workflow is present.

## Factual integrity

- [ ] Every curated JSON value has a source URL and locator.
- [ ] The paper result is 92.5% in the correct Table 1 row and AG column.
- [ ] The repository is pinned to the registered commit.
- [ ] No factual value originates from the generated mockups.
- [ ] The mini-news files are identified as project-authored, non-benchmark teaching data.
- [ ] No local result is seeded without an observed run.

## Behavior

- [ ] Intake opens the curated project.
- [ ] Reproduction Map separates paper benchmark from minimal target.
- [ ] Removing any required evidence invalidates checkpoint verification.
- [ ] Refresh preserves learner evidence.
- [ ] Passport status is deterministic.
- [ ] Markdown and JSON exports agree.

## Quality

- [ ] Typecheck, lint, tests, and production build pass.
- [ ] Core workflow is keyboard accessible.
- [ ] Desktop render matches the approved research-workbench direction.
- [ ] No primary content is clipped at a narrow viewport.
- [ ] Three-minute demo rehearsal succeeds from clean storage.

## Stop condition

Do not implement the remaining six checkpoints until this checklist is reviewed.
