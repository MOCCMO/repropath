# Three-Minute Demo Script

## 0:00–0:35 — Start with a bounded case

Open ReproPath and select the curated fastText project. Point out that the paper and repository facts are sourced and that no copyrighted paper file is bundled.

## 0:35–1:10 — Define the smallest honest target

Open the Reproduction Map. Contrast the paper's AG benchmark with the project-authored mini-news target. Emphasize that the two results are not numerically comparable.

## 1:10–2:10 — Record evidence

Open the single checkpoint. Enter or review environment, training command, evaluation command, log excerpt, and P@1 result. Remove one field briefly to show that verification is evidence-gated, then restore it.

## 2:10–2:50 — Generate the Passport

Open the Reproduction Passport. Show the pinned paper/repository versions, evidence, missing fields, explicit benchmark gap, and deterministic status.

## 2:50–3:00 — Export

Download Markdown and JSON. Close with: ReproPath does not merely show that a command ran; it records what target was attempted, what evidence supports it, and what remains unreproduced.
